# 헬스에이지 모바일 앱 사용설명서 — 페이지 구성 (A4 2페이지)

> 기준: `frontend-mobile` 최신 코드 (2026-11-15 확인). 앱 이름 **헬스에이지**.
> 하단 탭은 5개(홈·검사항목·히스토리·분석·업로드), 프로필은 헤더 우상단 사람 아이콘.
> 데모 계정: `root` / `1234` (Supabase 미설정 환경에서만 동작)

## 공통 기준
- 시니어 대상: 본문 11pt 이상, 큰 번호 원, 색에만 의존하지 않기(배지는 글자 병기)
- 앱 색: 초록(#00C073 계열), 문구는 앱 안의 표현(해요체, "참고 점수", 주의/위험 배지) 그대로
- 맨 아래 고정 문구: "참고용이에요. 걱정되면 의료진과 상담해 보세요."

## 1페이지 — 기본 플로우: "처음 시작해서 내 점수 보기"

상단: 앱 이름 + 한 줄 소개("검진 결과지 사진 한 장으로 내 건강 점수와 변화를 확인해요")

| 단계 | 화면 | 사용자가 하는 일 | 매뉴얼 문구 | 캡처 파일 |
|---|---|---|---|---|
| ① | 홈 → 로그인/회원가입 | 이메일·이름·생년월일·성별·비밀번호(6자 이상) 입력 | 처음이라면 회원가입부터 해요 | 01_login.jpg |
| ② | 생활습관 문진 | 흡연·음주 선택 (건너뛰기 가능) | 검진 수치로는 알 수 없어서 한 번만 물어봐요 | 02_lifestyle.jpg |
| ③ | 업로드 탭 | 카메라 촬영 / 갤러리 선택 (사진이 없으면 "검진지 없이 직접 입력") | 검진 결과지를 사진으로 찍어요 | 03_upload.jpg |
| ④ | 값 확인 | 읽은 값을 검진표와 비교하고 틀린 곳 수정 | 흐릿하게 읽힌 항목은 꼭 확인해요 (빨간 * 는 꼭 채워야 해요) | 04_review.jpg |
| ⑤ | 저장 | [확인한 값 저장하기] → "이 값으로 저장할까요?" → 저장하기 | 저장하면 분석이 바로 시작돼요 | 05_save.jpg |
| ⑥ | 홈 | 점수 확인 → 주의 항목 TOP 3 → 항목 상세 | 누르면 쉬운 설명과 해 볼 일이 나와요 | 06_home.jpg, 07_detail.jpg |

하단 한 줄: 점수는 0~100점, 40점 미만 관리 필요, 70점 이상 양호. 정상·주의·위험 개수도 함께 보여요.
(40·70은 코드의 점수 바 눈금 기준)

선택: ①②를 "가입"으로 합쳐 5단계로 줄일 수 있음.

## 2페이지 — 보조 플로우: "더 잘 쓰는 법"

상단 띠: 하단 탭 5개 아이콘과 한 줄 설명
> 홈(점수·주의 항목) · 검사항목(항목별 수치) · 히스토리(해마다 변화) · 분석(자세한 해석) · 업로드(자료 올리기) / 프로필은 화면 오른쪽 위 사람 아이콘

| 카드 | 제목 | 짧은 플로우 | 캡처 파일 |
|---|---|---|---|
| A | 먹는 약도 올리기 | 업로드 → 처방전·복약자료 탭 → 건강보험심사평가원에서 엑셀 저장(5단계) → 파일 선택 → (파일이 안 열리면 생년월일 8자리) → 검사항목의 "복용약 정보"에서 확인. 약 정보를 올리면 약 때문에 정상으로 보이는 항목까지 감안해 분석 | 10_med_upload.jpg, 11_med_list.jpg |
| B | 해마다 달라진 점 보기 | 히스토리 → "먼저 확인하세요" → "항목별로 보기" 그래프 | 12_history.jpg |
| C | 분석 탭 읽는 법 | 연도 선택 → ① 기준을 벗어났나 ② 계산으로 알 수 있는 값 ③ 또래와 비교 ④ 맞춤 권장사항 → "다음 검진 목표 세우기" | 13_analysis.jpg |
| D | 병원 갈 때 | 검사항목에서 연도 선택 → PDF로 내보내기(프로필에서도 가능). 홈 "빠른 이동"에서 검진기관·근처 병원·약국 찾기(로그인 없이 가능) | 14_records.jpg, 15_quicklinks.jpg |
| E | 내 설정 | 프로필: 내 정보 수정(비밀번호 입력 후) · 검진 일정 알림 · 쉬운 설명 우선 표시 · 로그아웃. 잘못 올린 기록은 검사항목의 휴지통 아이콘으로 삭제 | 16_profile.jpg |

하단: 참고용 안내 문구 + 문의 support@healthage.kr

## 제작 메모
- 코드와 어긋나지 않게 확인할 것: 프로필 "본인 확인"은 실제 비밀번호 검증이 아님(1234 또는 6자 이상이면 통과) → 매뉴얼에는 "수정하려면 비밀번호를 입력해요" 정도로만 표기
- 분석 탭 4단계 이름은 설계 문서 기준(코드 LAYERS 상수는 미확인)
- 캡처는 데모 계정(root/1234) 더미 데이터 기준. 사진 촬영·파일 선택 같은 기기 기능 화면은 웹에서 재현 불가할 수 있음

### 못 찍은 것 (데모 계정/웹 한계)
- 02 생활습관 문진: 실제 회원가입(Supabase) 직후에만 뜸
- 05 저장 확인 팝업("이 값으로 저장할까요?"): 예시 데이터에서는 저장 대신 안내창만 뜸. 실제 사진 업로드 필요
- 휴지통(기록 삭제): 실데이터 계정에서만 표시

### 캡처하며 발견한 점 (매뉴얼 문구에 영향)
- 점수 라벨은 "주의가 필요해요"(홈·분석), "주의 필요"(히스토리). 40점 미만 문구가 코드/설계 문서의 "관리 필요"와 다름 → 매뉴얼에는 화면 문구 그대로 사용
- 같은 데모 계정인데 점수가 40(홈·분석 일부)과 39(히스토리·분석)로 다르게 보임 → 매뉴얼 캡처 간 숫자 불일치 주의
- 히스토리·항목 상세의 그래프는 오른쪽이 잘려 보임(375px 폭 에뮬레이션 기준) → 그래프가 크게 나온 캡처는 실기기 캡처로 교체 권장
- 분석 탭 4단계 이름 확인: ① 기준을 벗어났나 ② 검진지에 없는 값을 만들어요 ③ 같은 또래는 어떤가 ④ 그래서 뭘 하면 되나
