# 태블릿 시안 (초안)

대상: 헬스에이지 모바일 앱의 태블릿 반응형(폭 600 이상). 시니어 사용자 기준.
시안: 같은 폴더의 `태블릿-시안/` (캔버스 파일. `Main`·`Cur-*`는 현재 앱, `Tab-*`는 태블릿 시안). 표시된 수치는 현재 앱의 데모 계정(root) 값 그대로.
색·글자 크기는 `기존설계-통합본.md` 6-1·6-3을 따름.

## 1. 현재 문제 (태블릿 폭에서)
1. 모바일 레이아웃이 그대로 늘어나 카드 한 줄이 너무 길다
2. 하단 탭이 화면 아래에 멀리 떨어져 엄지로 닿기 어렵다
3. 그래프만 커지고 정보량은 그대로다
4. 목록 → 상세로 들어갔다 나오는 이동이 많다

## 2. 반응형 기준 (제안)
| 폭 | 구조 |
|---|---|
| 600 미만 | 모바일 그대로 (하단 탭, 1열) |
| 600~1023 (태블릿 세로) | 좌측 레일 96px + 본문 2열 카드 |
| 1024 이상 (태블릿 가로) | 좌측 레일 + 검사항목 목록 3열 |

## 3. 화면별
| 화면 | 구성 | 비고 |
|---|---|---|
| 홈 | 좌 점수 카드 / 우 지금 주의할 항목 TOP 3 → 빠른 이동 4칸 한 줄 → 점수 변화 미리보기 | 점수 변화 카드는 새로 넣은 것 |
| 검사항목 | 탭 안에 **`검사 항목 \| 복용약 정보`** 선택 막대. 연도 칩 → 정상·주의·위험 칩 → 항목 17개 | 목록·상세 분할은 하지 않음 |
| 검사 항목 목록 | 항목마다 **개별 카드 버튼**(오른쪽 화살표 포함), 세로 2열·가로 3열. 열 우선 정렬이라 위험·주의가 왼쪽 열 | 제목줄에 "항목을 눌러 자세히 보기" |
| 복용약 정보 | 예시 안내 배너 → 효능군별 약 카드 2×2 → 복약자료 올리기 카드 | 올리기 카드는 새로 넣은 제안 |
| 항목 상세 | 기존처럼 전체 화면으로 열림. 세로는 2열(좌: 결론·값과 그래프·이 지표는요 / 우: 또래와 견주면·이렇게 해 보세요), 가로는 3열 | 시안은 LDL-C 한 항목, "왜 그럴까요?"는 접힌 채 |
| 히스토리 | 점수+결론(좌)과 추이 그래프(우)를 한 카드로 → 먼저 확인하세요 2열 → 항목별로 보기 2열 | 아래 5절 참고 |
| 분석 | 점수 요약 한 줄 카드 → 네 층을 2×2 카드로 | 문구는 현재 앱 그대로 |

## 4. 통합본 기준 적용
- 색: 정상 `#1D7F56`, 주의 `#A95D05`, 위험 `#D71121`, 배경 `#F3F5F7`, 브랜드 그린 `#00C073`·글자 `#00814D`. 큰 숫자·막대는 Fill 색(`#FD6400` 등)
- 글자: 14 / 16 / 18 / 20 / 24, 14 미만 없음. 버튼 라벨 18
- 카드 radius 20, 버튼 14, 터치 48 이상, 카드 간격 12
- 상태는 색 + 모양(■ ● ▲) + 글자

## 5. 아직 정하지 않은 것
- 초록 버튼 글자색: 통합본 6-2는 흰색이지만 같은 문서가 대비 2.4:1(AA 미달)이라고 적음. 히스토리 개선안은 어두운 글자(`#06281C`). 시안은 흰색
- 히스토리 탭은 현재 앱 구조 기준. `히스토리탭-개선안-확정.md`(큰 점수 + 한 줄 결론 + 범례 등)는 아직 태블릿에 반영 안 함
- 폰트는 Pretendard 지정, 캔버스에서 없으면 Noto Sans KR로 보임
- 항목 상세: 그래프 2008~2020년 점은 앱 그래프에서 읽은 근사치(2022년 147, 2024년 145만 확인). "왜 그럴까요?" 펼친 근거 줄은 못 봄
- 업로드 탭 태블릿 시안 없음. 인터랙션(탭 전환, 연도 이동, 접힘)은 미설계
- 폰 가로(600 미만 가로) 처리는 미정
