# 히스토리 탭 개선안 (확정)

대상: 헬스에이지 모바일 앱 히스토리 탭과 항목 상세. 시니어 사용자 기준.
시안: 같은 폴더의 `Main.dc.html`(히스토리 탭), `Detail.dc.html`(항목 상세). 표시된 수치는 모두 예시 데이터.

## 1. 현재 문제 (요약)
1. 정보가 한 화면에 너무 많고, 같은 모양의 카드가 반복되어 우선순위가 안 보임
2. 배지 글자가 11px로 작고 색에만 의존
3. 종합 해석이 화면 아래쪽에 묻혀 있음
4. 그래프에 숫자 라벨이 적어 읽기 어려움
5. 카드 상세에서 "이 지표는요 → 자세히 알아보기"의 2.5뎁스 라벨이 모호함

## 2. 히스토리 탭 (Main)
| 순서 | 내용 | 비고 |
|---|---|---|
| 1 | 큰 점수 "22점" + "관리 필요" 배지 | 배지는 모양+글자 (색만 쓰지 않음) |
| 2 | 한 줄 결론 "2020년 이후 점수가 오르고 있어요." | 1뎁스 |
| 3 | 단순화한 추이 그래프 | 라벨은 100 / 14 / 22, 연도는 2012 / 2020 / 2024 |
| 4 | 범례: 점선 원 = 일부 검사가 빠진 해 | 문장 대신 그래프 점과 같은 모양의 아이콘 |
| 5 | "먼저 확인하세요" (2행) | |
| 6 | "항목별로 보기" (5행) | 지질·혈당·체중 주의 / 혈압·혈액·신장·간 기능 정상, 행마다 배지 + 한 줄 |
| 7 | 링크 2행: "또래보다 빨리 변한 항목", "그 밖의 변화 보기" | |
| 8 | 안내 "참고용이에요. 걱정되면 의료진과 상담해 보세요." | |

## 3. 항목 상세 (Detail) — 2뎁스 5칸 구조
| 칸 | 내용 |
|---|---|
| ① 결론 | "나쁜 콜레스테롤이 12년 동안 33 올랐어요." (22px) |
| 값 영역 | 항목 탭 4개, 그래프(정상 130 미만 띠), 이전 해/다음 해, 값 151 mg/dL + "정상보다 높아요" 배지 |
| ② 이 지표는요 | 쉬운 말 1~2문장 + 접힌 **"왜 그럴까요?"**(2.5뎁스: 기준 / 내 값 / 근거 3줄) |
| ③ 나의 위치 | "또래와 견주면" 같은 나이대 100명 중 78등, 슬라이더 |
| ④ 의미 | "그래서 어떤 뜻이에요?" |
| ⑤ 행동 | "이렇게 해 보세요" 3개 |

2.5뎁스는 앱에서 접힌 채 시작한다. 시안에서는 구조를 보이려고 펼친 모습으로 둠.

## 4. 시니어 접근성 기준
- 본문 15~17px 이상, 터치 영역 44~52px 이상
- 본문과 상태 글자 대비 4.5:1 이상 (주의 #A8520A, 정상 #1B7A4B, 위험 #C4281C, 보조 #4E5968)
- 상태는 색 + 모양 + 글자로 함께 표시
- 초록 버튼은 어두운 글자 (#06281C on #00C073)

## 5. 아직 정하지 않은 것
- 2.5뎁스 근거를 공식·논문 수준까지 쓸지, "기준보다 21 높아요" 수준에서 끝낼지 (6줄 초과 시 3뎁스 검토)
- 시안의 근거 출처 문구 "이상지질혈증 진료지침의 기준값"은 자리 표시용 예시
- 항목별 수치(좋은 콜레스테롤, 중성지방 등)는 아직 시안에 없음
- 인터랙션(항목 탭 전환, 연도 이동, 접힘)은 미설계
