## 2. 주요 작업 상세

### 2-1. A 또래비교 + D 중복접기 (검증 후 커밋)
- **A**: `backend/app/analyzer/_internal/calculator_percentile.py` 신규. `peer_percentile(key, value, gender, age)`가 컷오프 미확립 5종에 "한국인 55세 남성 중 상위 X%" 부착(기준분포 = 2017 국가검진 전수, 성×연령대). 조회 불가 시 None(추정 금지).
- **D**: 대사·지질 계산기 20종이 실은 4개 축(문서 20 D분석) → 대표 TyG·Non-HDL·MAP만 펼치고 강상관 중복 6종 접기.
- 검증: 백엔드 e2e(TyG 9.1→상위32%·METS-IR 45→상위10%), 웹 playwright 실화면(D 접기 확인), tsc0.

### 2-2. A 재분석 — 저장 리포트 소급 반영
- 문제: 저장된 analysis_results는 A 코드 이전이라 peer_label 없음 → 화면에 또래비교 안 뜸.
- 해결: `reanalyze_reports.py` — checkup_records를 ocr_json으로 역변환 → `analyze_and_save(save=False)` 재분석 → analysis_results를 서비스 클라이언트로 **in-place UPDATE**(checkup·timeseries 불변).
- 결과: 데모 4건 반영. 웹 실화면에서 "또래비교 · 한국인 44세 남성 중 상위 28%" 렌더 확인. 계산기 0종이던 옛 리포트 2건도 복구.

### 2-3. 약국찾기 아이콘 — 투톤 알약
- 반창고 → 알약. Ionicons/MCI 단색 폰트로는 반쪽 검정·반쪽 흰색 투톤 불가 → `react-native-svg`로 PillIcon 직접 그림(캡슐 -45° 회전, 좌하 검정 채움 + 우상 흰색 + 검정 테두리).
- `frontend-mobile/src/screens/DashboardScreen.tsx`.

### 2-4. root 풀 더미 combo (★핵심)
- **문제**: root 더미 계정은 `comboAnalysis`가 없어 분석탭에 "관리 참고군"까지만 나오고 계산기·조합·A또래비교·시계열이 전부 비어, **초기버전과 구분이 안 됐다**(에뮬레이터 2대 비교로 확인).
- **해결**: `frontend-mobile/src/dummyAnalysis.ts` 신규.
  - root 2024 검진값(홍길동 50세 남: sbp138·bmi26.3·waist93·glucose112·ldl145·hdl39·tg178 등)을 **백엔드 `analyze()`에 넣어 나온 실제 combo_analysis·recommendations를 그대로 임베드**(수치·정합성 실제와 동일, 지어낸 값 아님).
  - highlights·insight(시계열)만 6개년 악화 스토리로 수작업.
  - `App.tsx`가 데모 모드(isDemoAccount)일 때 null 대신 이 더미(combo·recommendations·highlights·insight)를 화면에 전달.
- **판정불가 조합 렌더 신규**: `AnalysisScreen`에 not_evaluable 리스트 추가 — "입력값 없어 지어내지 않고 판정불가로 둔 조합"(정직성). 실데이터에도 동일 적용.
- 검증(에뮬 root): 계산기·A또래비교배지·D중복접기·조합 O/E·판정불가·집단군13·ASCVD시뮬·대사5인자·시계열 전부 렌더.

### 2-5. 백엔드 미표시 기능 2종 노출
백엔드가 만들지만 응답에서 버려지던 것을 살림:
- **① LDL 위험도별 개인 목표치** (`clinical_targets.classify_ldl_risk`)
  - `checkup_service`가 `ldl_target`을 combo_analysis에 주입(1줄; 그동안 group_analysis에만 있어 버려짐).
  - `AnalysisScreen` "LDL 콜레스테롤 개인 목표" 카드 — 위험군별 목표(중등도<130 등)·현재값·달성/초과(+15)·반영 위험인자·한계·지침 출처.
- **② 시계열 종합 insight** (`insight_generator.generate_insight`)
  - `RealTimeseries.insight` 타입 추가, App.tsx가 HistoryScreen에 전달.
  - `HistoryScreen` "한눈에 요약" 카드 — 종합 요약 + 주요 우려 Top 3 + 다음 검진 권장.
- dummyAnalysis.ts 재생성으로 root 데모에도 반영.

## 5. 운영 메모 / 주의사항

- **`frontend-mobile/.env`**: ✅ **터널 값으로 복원 완료**(작업 말미). 에뮬 로컬 검증이 필요하면 파일 안의 `# EXPO_PUBLIC_BACKEND_URL=http://127.0.0.1:8000` 주석을 켜고 터널 줄을 끄면 된다(+ `adb reverse tcp:8000 tcp:8000`). gitignore라 커밋엔 안 잡힘.
- **앱 리포트 로딩**: 앱은 `apiFetch('/reports/*')` → `EXPO_PUBLIC_BACKEND_URL`에서 읽음. (문서 21의 "supabase 직접조회" 서술은 부정확 — 실제는 백엔드 경유. 단 **root 데모는 백엔드 불필요**한 오프라인 더미.)
- **root 데모 = `root`/`1234`** (`EXPO_PUBLIC_ENABLE_DEMO=1`). 이제 풀 더미로 전 기능 오프라인 시연 가능. 실데이터 시연은 `webdemo40680@example.com`/`(비밀번호 가림)`(백엔드·터널 필요).
- **dummyAnalysis.ts 재생성법**: `backend/.venv/Scripts/python.exe`로 root 2024 값을 `analyze_and_save(save=False)`에 넣어 combo·recommendations 추출 → 임베드. highlights·insight는 수작업.
- **에뮬레이터 2대 셋업**: AVD `withus`(5554, 현재버전) + `withus2`(5556, `avdmanager create`로 복제, Expo Go APK를 withus에서 pull해 install). Metro 8081(현재)·8082(초기버전 `input/코드/헬스에이지 초기버전`). adb reverse tcp:8000/8081/8082로 에뮬→호스트 연결(Windows 방화벽 우회).
- **약국찾기 등 QUICK_LINKS 링크**: 검진기관=NHIS, 근처병원=E-Gen, 약국=HIRA getHealthMap(병원·약국 종합 지도).
