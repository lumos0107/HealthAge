## 1. 세어 보니 두 칸이 비어 있었다

층은 기능별(판정→계산→비교→행동)로 짜여 있는데, 데이터 종류 × 기능으로 세면 이랬다.

| | ① 판정 | ③ 또래 비교 | ④ 행동 |
|---|---|---|---|
| 단순 수치 | ✅ | △ 검사항목 탭에만 | ✅ |
| 단일 그룹 | ✅ | △ 7/13 | ✅ |

## 2. 만들어 놓고 안 닿던 것 — 딕셔너리 6줄

원자료를 다시 돌려야 하는 줄 알았는데, **데이터는 이미 다 있었다.**

```
calculator_percentiles_2017.parquet  10종  ↔  KEY_TO_INDICATOR  5종만 매핑
single_groups_16yr.parquet           13종  ↔  _TREND_GROUPS     7종만 통과
```

- **계산기 또래 5 → 10종** (Non-HDL·Castelli I·II·De Ritis·MAP)
- **단일그룹 또래 7 → 8종** — `g_pre_hypertension`만 더한다. 당뇨 전단계는 있는데
  고혈압 전단계만 빠진 누락이었다.

**흡연 3종·음주 2종은 일부러 넣지 않았다.** 문진 기반 «행동»이라 「또래 100명 중
32명이 흡연해요」가 판단을 돕기보다 **「나만 그런 게 아니네」로 읽혀 행동을 막는다.**
유병률은 상태를 상대화할 때 쓰는 것이지 행동을 상대화할 때 쓰는 것이 아니다.

### 컷오프가 있는 지표에 또래를 달 때

새로 매핑한 5종은 **컷오프가 있는** 지표다. 그래서 또래는 판정을 대신하지 않고 **보조**로만
쓴다 — 결론은 학회 기준이 말하고 백분위는 그 아래 작은 줄이다. 「또래 평균 근처면
괜찮다」로 읽히면 ③층 「또래 자체가 나빠졌나」가 경고하는 바로 그 오독이 된다.

## 3. 조합그룹 → 행동 (A-1)

조합이 개별 판정에 더해 주는 것은 **두 항목의 관계**다. 관계를 알면 순서가 나온다 —
같은 원인이면 하나만 잡아도 둘이 움직이고, 다른 축이면 따로 잡아야 한다.
기록 36 §4-2의 설계대로 12개를 네 유형으로 묶었다.

| 유형 | 뜻 | 예 |
|---|---|---|
| `same_cause` | 같은 원인에서 함께 나옵니다 | 비만+지방간 — 내장지방이 둘을 같이 만들어요 |
| `one_worsens` | 하나가 다른 하나를 밀어붙입니다 | 음주+지방간 — 절주가 첫 순서예요 |
| `different_axis` | 서로 다른 축이라 위험이 곱해집니다 | 고혈압+이상지질 — 하나만 잡으면 다른 하나는 그대로 |
| `shared_criterion` | 판정 항목을 공유합니다 | 대사증후군+비만 — 허리 하나가 둘을 같이 움직여요 |

## 4. 계산기 → «내 값» 기반 행동 (A-2)

카드 ⑤가 「TyG가 높으면 체중·탄수화물 관리가 우선이에요」였다. **TyG가 낮아도 똑같이
나오는 고정 문구**다(기록 36 #8).

각 입력을 또래 중앙값으로 바꿔 보면 어느 쪽이 기여했는지 정확히 나온다. 기여도는
공식의 형태에 맞춰 같은 자로 잰다:

| 계산기 | 공식 | 기여도를 재는 자 |
|---|---|---|
| TyG | `ln(TG) + ln(FBS) − ln2` | 로그 차 (정확히 더해진다) |
| Non-HDL | `TC − HDL` | mg/dL 차이 (HDL은 부호 반전) |
| AIP | `log10(TG/HDL)` | 비율의 로그 |
| MAP | `(SBP + 2·DBP)/3` | 가중치를 곱한 mmHg |

```
TG 189 / FBS 105  → 「중성지방 쪽이 이 값을 더 끌어올렸어요」
TG 100 / FBS 130  → 「공복혈당 쪽이…」
정상 범위          → None (지어내지 않는다)
```

1위가 2위의 1.5배 미만이면 «둘 다»로 말한다 — 근소한 차이를 단정하지 않는다.

⚠️ **아직 절반이다.** driver가 «왜 이 값인지»는 짚지만 «그래서 뭘 하라»는 여전히
고정 문구다. 「중성지방이 끌어올렸다」 → 「그러면 술·당류부터」로 이어져야 완성이다.

## 5. 조합그룹을 다시 본 것 — 사용자 지적에서 시작

「조합그룹은 그냥 찾아낸 규칙 아닌가, 검증에서 대부분 못 쓴다 하지 않았나,
우리가 멋대로 의미를 부여하는 것 아닌가, 애초에 필요한가」

증거를 확인했다. **셋 중 하나는 지적이 맞았다.**

| 물음 | 확인 |
|---|---|
| 규칙 마이닝인가 | **아니다.** 임상적으로 고른 12개에 동반빈도를 잰 것. 순서가 반대 |
| 검증에서 대부분 탈락했나 | **아니다.** 버린 것은 조합이 아니라 «연도»다(2026-07-29 재분석 §3-B) |
| 멋대로 의미를 부여했나 | ✅ **맞다.** `relation`·`action`은 임상 지식으로 쓴 상수인데 화면이 O/E와 같은 무게로 보여줬다 |

### 그래서 셋을 고쳤다

**① 카드를 ③층에서 ④층으로 옮겼다.** 「흔한가」는 답을 알아도 할 일이 안 바뀌고
(축 0 판별 테스트), 바로 위 「나 같은 사람이 얼마나 되나」와 **화면에서 같은 질문으로
읽혔다.** 정작 쓸모 있는 것(관계 → 순서)은 또래 이야기가 아니라 행동 이야기다.

```
전  ③ 이 조합이 흔한가 — 조합 4개 · 같은 조합인 사람은 100명 중 10명이에요
후  ④ 같이 잡아야 할 게 있나 — 2개 조합 중 1개는 하나를 잡으면 함께 움직여요
```

**② O/E를 결론에서 «근거»로 내렸다.** 사라지지 않는다 — 「왜 이 둘을 같이 보라는
건가」의 답이 되어 오히려 제 역할을 한다(§1-1 자산은 죽이지 않는다).

**③ O/E 1.5 미만은 행동으로 내세우지 않는다** (12→8, 화면상 4→2).

```
당뇨+고혈압+이상지질혈증  2.93        고혈압+이상지질혈증  1.37  ← 아래는
비만+이상지질+지방간      2.67        대사증후군+흡연      1.32     내세우지
…  당뇨+이상지질혈증      1.53        비만+당뇨전단계      1.24     않는다
                                      음주+지방간의심      1.15
```

**재현성과 효과크기는 다르다.** 1.15는 «재현성 있게 약한 것»이다. 지우지는 않고
근거 목록에 값과 함께 남기고, 왜 뺐는지 화면이 밝힌다.

**④ 출처가 둘이라는 것을 화면이 말한다.**
> «몇 배 동반»은 공단 표본에서 센 값이고, «왜 같이 나타나는지»는 임상 지식에 따른 설명이에요.

## 6. 또래 비교의 기준연도 — 2017 고정은 의도였다

`calculator_percentiles_16yr.parquet`(4,392행)이 참조 0건이라 조사하다 더 큰 것이
나왔다. **계산기 또래가 2017 한 해로 고정**돼 있었다. 2024년 검진을 2017년 또래와
견주는 셈인데, ③층이 「16년 새 비만 21%→46.1%」라고 말하는 앱에서 그냥 넘길 일이 아니다.

그런데 **2017 고정은 실수가 아니라 의도**였다. 2018년 지질검사 4년주기 전환 이후
지질을 잰 사람만 분모에 들어가고, 그 부분집합은 이미 관리 중인 쪽으로 쏠려 있다.
표본 수로도 보인다:

```
2024년 · 남 55~59세   TyG 16,295 · Non-HDL 16,307   ← 지질: 1/3만 측정
                      De Ritis 50,466 · MAP 50,466  ← 전수
```

그래서 갈랐다. **전수 측정되는 De Ritis·MAP만 검진 연도**로 견주고(16년 파일 사용),
지질 기반 8종은 2017 고정을 유지한다. 어느 해 기준인지는 `peer_year`로 화면이 밝힌다.

### 데모 백분위도 같은 실수를 했다

항목별 백분위(C-4)를 뽑을 때 내가 `year=2017`로 고정했다. 실서비스는 검진 연도를
넘긴다(`compare_to_peers` 기본값 2024). 8개 회차를 당해연도 기준으로 교체했고,
2008년은 `peer_stats`가 2009년부터라 실측이 없어 「(어림)」으로 뒀다.

## 7. 곁들여 고친 것

| 무엇 | 내용 |
|---|---|
| 크레아티닌 밴드 문구 | 「정상 **기관 기준 확인mg/dL**」 → 숫자가 있을 때만 단위를 붙인다 |
| `simulateDemo` 성별 | 허리 90·HDL 40 고정 → `gender`로 85/50 분기. 같은 화면 `MS_CRITERIA`가 이미 성별 분기가 있어 **여성이면 두 계산이 갈라졌다** |
| 항목별 또래 실측 | 데모가 전부 「(어림)」이었다 → 실측으로. 근사가 실제보다 나쁜 쪽으로 치우쳐 있었다(BMI 82→64등) |
| 백엔드 조사 처리 | `_josa()` 신설. 「이완기혈압와 수축기혈압가」가 나왔다(기록 36 §7-6) |
| 「계산기 22종」 문구 | **실제는 23종.** `additional_calculators`는 이력상 14→15였고 22였던 적이 없다. 셀 수 없는 자리의 숫자를 뺐다 |
| `hitSlop` | 12 → 36곳. 터치면적이 이미 큰 것(카드·칩)은 대상에서 뺐다 |
| `Collapsible` | 사용처 0건. 지우지 않고 «새로 쓰지 말 것, Expandable을 쓸 것» 주석만 달았다 |

### 글자 크기 조항 개정 (§7)

「본문 16 미만 금지」였는데 실측하면 16 이상은 약 50곳뿐이고 본문 대다수가 13~15다.
**§8이 스스로 「L1부터 뱅샐 밀도」라고 적어** 두 조항이 부딪히고 있었다. 검진 항목이
17개인 화면에서 16pt 본문은 애초에 담기지 않는다 — **규칙 쪽이 틀렸다.**

| 역할 | 하한 |
|---|---|
| 읽는 문장(①결론·②정의·④의미·⑤행동) | 13 |
| 보조 캡션(근거·출처·한계·단위) | 11 |
| 배지·칩 라벨 | 10 |

가르는 기준은 «문장인가»다.
