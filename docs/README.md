## 폴더

| 폴더 | 내용 |
|---|---|
| `planning/` | 첫 제안, 회의와 교수 인터뷰, 일반인 설문 |
| `evidence/` | 진료지침 원문 검증, 조합그룹의 의학 출처, 생활습관 효과 근거 |
| `analysis/` | 분석 모델 목록, 분석 체계 재정립, 공단 표본 16년 분석과 재현 스크립트 |
| `design/` | 화면·기능 설계와 개발 기록(2026-07-22\~08-03) |
| `specs-plans/` | 기능별 설계서와 구현 계획 |
| `presentations/` | 대회 발표자료, 결과보고서, 부스 포스터, 전시 그림 |

## 읽을 때 참고

- 개발하면서 쓴 기록이라, 뒤에서 판단을 바꾼 부분도 지우지 않고 남겼습니다.
- 문서 속 `정리/`, `input/` 같은 경로는 팀 작업 폴더를 가리키며 이 저장소에는 없습니다. 진료지침 PDF, 공단 원자료, 설문 응답 원본, 자문 녹취는 넣지 않았습니다.
