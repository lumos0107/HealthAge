# 모바일 앱 디자인 개편 — 토스 구조 × 뱅크샐러드 컬러 (2026-07-28)

## 목적

`frontend-mobile`의 현재 무신사 스타일(무채색·직각·full-bleed 구분선)을
토스·뱅크샐러드 문법으로 전면 교체한다.

**핵심 원칙: 구조·컴포넌트는 토스, 브랜드 컬러만 뱅크샐러드.**
카드 리듬·리스트 행·버튼·입력·탭바 등 화면 문법은 토스를 따르고,
뱅크샐러드에서 가져오는 것은 브랜드 그린 하나다.

## 전제 (사용자 확정)

- 참고 요소 4종 전부: 카드 레이아웃 · 포인트 컬러 · 타이포/숫자 강조 · 마이크로카피 톤
- 포인트 컬러: 뱅크샐러드 그린 (`#00C073` 계열)
- 범위: 화면 6개 + 탭바·헤더·로그인 모달·공통 컴포넌트 일괄
- **기능·정보 100% 유지** — 보이는 정보·기능은 하나도 빼지 않고 시각 스타일과 카드 묶음·순서만 재구성
- 접근 방식 A: 토큰·공통 컴포넌트 먼저 교체 → 화면별 순차 리스킨. 로직(데이터 로딩·계산·상태) diff 0

## ⛔ 이번 단계가 아닌 것 (누락 아님 — 의도적 이월)

이번 단계는 **시각 개편만** 다룬다. 아래는 다음 단계로 명시적으로 이월한다:

1. **정상범위 표기 방식 변경** — 수치 옆 정상범위 표기 형식·위치 개선
2. **해석 문장(인사이트 카피) 개편** — 수치 해석·안내 문장의 내용 재작성
3. **차트 밴드(정상범위 음영 등) 도입** — 그래프에 정상범위 밴드 오버레이

구현 계획(plan)에도 이 세 가지가 "다음 단계"임을 기록할 것.
이번 단계에서 기존 표기·문장·차트는 스타일만 바꾸고 내용·형식은 그대로 둔다.

## 1. 디자인 토큰 (`src/components/UI.tsx`의 `T` 교체)

| 토큰 | 현재 (무신사) | 변경 (토스 구조 × 뱅샐 컬러) |
|---|---|---|
| 화면 배경 `bg` | `#FFFFFF` | `#F3F5F7` (토스 그레이) |
| 카드 | 흰색 + 테두리 `#E5E5E5` + radius 4 | 흰색, **테두리 없음**, radius 20, 카드 간 12 |
| 포인트 `primary` | 블랙 `#1A1A1A` | **뱅샐 그린 `#00C073`** · 눌림 `#00A862` · 틴트 `#E6F9F1` |
| 텍스트 | `#191919` / `#5C5C5C` / `#9A9A9A` | 토스 잉크 `#191F28` / `#4E5968` / `#8B95A1` |
| 상태 정상 | `#3CB371`, 배경 회색 | **딥그린 `#1F8A5D`** + 틴트 `#EAF7F1` |
| 상태 주의 | `#FF8A3D`, 배경 회색 | **딥 앰버 `#D97706`** + 틴트 `#FFF3E7` (밝은 주황은 틴트 위 대비 부족으로 어둡게 조정) |
| 상태 위험 | `#F44336`, 배경 회색 | `#F04452` + 틴트 `#FEE9EB` |
| 구분선 | `#E5E5E5` full-bleed | 카드 내부 전용 옅은 선 `#F2F4F6` |
| 그림자 | 사실상 없음 | 없음 — 배경 대비로만 카드 구분 |
| radius | 4 / 8 / 999(버튼) | 카드 20 · 버튼 14 · 입력 12 · 칩 999 |
| eyebrow | 대문자·자간 1.6 라벨 | **폐기** → 일반 회색 캡션 13px (컴포넌트는 호환 유지, 스타일만 교체) |

**그린 역할 분리 규칙 — "누를 수 있는 것만 브랜드 그린"**
- 브랜드 그린 `#00C073`: 버튼·링크·활성 탭·인터랙션 아이콘 전용
- 상태 딥그린 `#1F8A5D`: '정상' 배지·수치·상태 텍스트 전용
- 색조(선명 vs 차분)와 역할(인터랙션 vs 상태)을 동시에 분리해 혼동 차단

## 2. 레이아웃 문법 (토스)

- full-bleed 구분선 폐기 → 연회색 배경 위 흰 카드 묶음 (좌우 마진 16~20)
- 카드 내부 리스트 행: 옅은 틴트 스쿼클 아이콘 + 제목/캡션 + 우측 값
- 버튼: 필(999) → 큰 사각라운드 radius 14, 브랜드 그린 채움
- 입력 필드: 테두리 박스 → 테두리 없는 연회색 채움 `#F2F4F6`, radius 12
- 헤더: 배경과 한 몸(연회색·그림자 없음). 탭바: 흰색 + 활성 아이콘 브랜드 그린
- 기존 애니메이션(FadeInUp·FadeIn·AnimatedScore)·Collapsible 동작 유지

## 3. 타이포·숫자

- Pretendard 유지 (이미 전역 적용)
- 페이지 타이틀 34 → 24~26 (토스는 화면 제목이 작고 콘텐츠 숫자가 큼)
- 점수 대형 숫자(64~80)는 유지 — 큰 볼드 숫자 + 작은 회색 캡션 대비
- letterSpacing −0.5 수준 유지, eyebrow식 uppercase·넓은 자간 제거

## 4. 마이크로카피

- 기존 "~해요" 체 유지. 정보가 담긴 문구는 변경하지 않는다
- 딱딱한 라벨("확인 필요" 등)만 토스 톤으로 소폭 다듬기. 이모지 사용 안 함
- 해석 문장 내용 개편은 다음 단계(위 ⛔ 참고)

## 5. 화면별 적용 (기능·정보 100% 유지)
