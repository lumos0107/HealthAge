## 1. API 진입점 / 최종 필드 구조

두 개의 독립 진입점 + 별도 시계열 경로:
- **분석 파이프라인** (`app/analyzer/`): `POST /analyze` → 서비스 조립 `checkup_service.py:120-167`
- **신장 모듈** (`app/renal/`): `POST /renal/egfr` (파이프라인과 무관, 별도 엔드포인트)
- **시계열** (`app/analyzer/_internal/timeseries_*`): `analyze_timeseries()` → `timeseries_service.py`

`run_full_pipeline()`(pipeline.py:604-641)는 `basic_report / comprehensive / group_analysis / recommendations`를 반환하고, 서비스 계층이 최종 API 필드 5개로 재배치한다.
**주의: `combo_analysis`는 `group_analysis` 안에서 꺼내져 최상위로 승격되고, 여기에 `single_groups`(단일그룹 13 표시용)·`ascvd_simulation`이 추가로 얹힌다** (checkup_service.py:124-132, `_single_groups_for_display` 274-289).

| 최종 API 필드 | 담기는 산출물 |
|---|---|
| `basic_report` | 종합 리포트 + 항목별 값/임상판정/백분위/해석 + 대사증후군(수치기준) |
| `comprehensive` | 전 항목 상태평가(10단계→3단계) + by_status + risk_score + summary + peer_comparison |
| `recommendations` | 공통/인자별/그룹별/약물/노인 권장 + priority_messages |
| `group_analysis` | user_groups(13) + metabolic_syndrome_detail(약물결합) + rarity + ldl_target + ascvd_simulation (+ 내부 combo_analysis) |
| `combo_analysis` (승격·증강) | combo_groups(12조합 O/E) + fatty_liver(유형+FLI/HSI) + **single_groups**(13) + **ascvd_simulation** |
| 별도: `renal` | eGFR + 병기/severity + CrCl + CrCl 라벨 |
| 별도: `timeseries` | metrics + highlights + exam_pattern + full_timeseries + insight |

## 3. 백엔드 상세 인벤토리

### 3-1. `comprehensive` (run_comprehensive_analysis, pipeline.py:100-258)
`all_evaluations`(항목별 status·percentile·peer_mean·peer_comparison), `by_status`(10단계 버킷), `summary`(total/risk/warning/normal/elderly count·risk_score·overall_status). risk_score=상태 가중합(190-198), overall=5단계.

### 3-2. 단일 집단군 13 — `GROUP_INFO` (user_group_analysis.py:25-47)
판정 로직 `classify_user_groups`(252-349). 대사증후군·당뇨·고혈압·이상지질은 **수치 OR 약물** 결합.

**임상 8**: ①고혈압(SBP≥140/DBP≥90/약) ②고혈압 전단계(130-139/80-89) ③당뇨(FBS≥126/약) ④당뇨 전단계(100-125) ⑤대사증후군(5중 3+) ⑥비만(BMI≥25) ⑦이상지질혈증(LDL≥160/HDL미달/TG≥200/약) ⑧지방간 의심(ALT>40/GGT>75)
**생활습관 5**: ⑨현재흡연 ⑩과거흡연 ⑪비흡연 ⑫음주 ⑬비음주

### 3-4. 대사증후군 평가 — `evaluate_metabolic_syndrome` (user_group_analysis.py:81-246)
5인자 각각 met/value/threshold/reason/**by_medication**: 복부비만(허리 남≥90/여≥85) · 고혈압(≥130/85 OR 약) · 고혈당(FBS≥100 OR 약) · 낮은HDL(남<40/여<50 OR 약) · 고TG(≥150 OR 약). 반환 factors/count/evaluable/is_metabolic_syndrome.
> 대사증후군은 **두 곳에서 산출**: basic_report(수치만, `health_report.check_metabolic_syndrome` 139-204) vs group_analysis(약물결합).

### 3-5. 희귀도 — `calculate_group_rarity` (user_group_analysis.py:419-452)
clinical_groups/lifestyle_groups/count + interpretation(위험요인 개수별 5단계: 0=건강\~4+=고위험 패턴). **모집단 빈도 조회 아님, 개수 기반 해석**.

### 3-6. 지방간
- **유형 분류** `classify_fatty_liver_type` (combo_group_analysis.py:370-459, 2025 MASLD 지침): 심장대사 위험인자 5종 + 음주량 3구간(MASLD 남≤210/여≤140, MetALD 중간, ALD 남>420/여>350). 산출 applicable/type/**provisional**(음주량 미수집 시 잠정)/basis/cardiometabolic_factors/note.
- **보조지표** `fatty_liver_indices` (clinical_targets.py:254-289): **FLI**(Bedogni 2006, BMI·허리·TG·GGT, <30/30-59/≥60) · **HSI**(Lee 2010 한국인, ALT·AST·BMI+성별·당뇨, <30/30-36/>36). value/level/interpretation/cutoffs/formula + unavailable + disclaimer.

### 3-7. LDL 목표치 — `classify_ldl_risk` (clinical_targets.py:94-159, 2022 한국 지침) — **미반영**
위험인자(`_count_risk_factors` 68-91): 흡연/고혈압/낮은HDL/연령(남45·여55+). 등급: 당뇨=<100, 위험 2+=<130, 1이하=<160. very_high(<55)/high(<70)는 병력 필요라 검진만으론 참고용. 산출 risk_level/label/target_ldl/current_ldl/achieved/gap/risk_factors/basis/on_medication/limitations.

### 3-8. ASCVD — `run_ascvd_simulation` (ascvd.py:147-235)
Pooled Cohort Equations(2013 ACC/AHA), 40\~79세. what-if 시나리오(금연/SBP120/HDL60). 산출 available/is_simulation/risk_percent/risk_level(low/borderline/intermediate/high)/risk_label/inputs/scenarios/method/limitations/how_to_read. **한국인 미검증·과대추정 명시, 진단 아닌 비교용**. TC 없으면 available=False.

### 3-9. 신장 — `analyze_renal` (renal/gfr.py:139-162, 별도 엔드포인트)
eGFR(CKD-EPI 2021, 인종항 제거) + 병기(G1\~G5)+label+description+**severity**(색상용) + CrCl(Cockcroft-Gault, 체중 있을 때만, 약물용량 참고) + CrCl 라벨/note(30/50/80 경계). **파이프라인 응답 미포함**.

### 3-10. 시계열 — `run_timeseries_pipeline` (timeseries_pipeline.py:20-99, history<2면 available=False)
- `analyze_timeseries`(157-315): metrics(항목별 변화량 vs 모집단), highlights(빠른변화·지속악화/개선), **exam_pattern**(다음 검진 예정연도·주기·누락), year_range
- `analyze_full_timeseries`(timeseries_full.py:77-230): by_direction(bad/good/neutral/stable), summary
- **`generate_insight`**(insight_generator.py:403-443): 자연어 summary/top_concerns(우려 TOP3)/recommendations/positive_changes/next_exam_year
