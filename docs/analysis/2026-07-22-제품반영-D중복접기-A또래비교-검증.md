## 4. A 문헌 대조 결과 (20번 A-4 요약)

병렬 조사 2건으로 최우선 5종을 한국·동아시아 코호트와 대조. **우리 2017 전수 산출값이 문헌과 강하게 일치**, "컷오프 미확립" 판정도 5종 모두 정확.
- TyG 8.80 ≈ 한국 MetS 최적컷 8.81(Shin 2019, PMID 31807040)
- METS-IR 36.5 ≈ 한국 분포(Yoon 2021), 멕시코컷 50.4는 우리 p95도 초과 → 부적합
- AIP 정점 0.08 = KNHANES 평균(Shin 2022) / LAP KoGES와 최고 일치(Kim 2018) / VAI 동시대검진 일치
- **우리 100만 전수 데이터가 소표본 문헌보다 견고**(VAI는 문헌끼리도 2배 차 → 백분위 방식 우월).

## 5. 에뮬레이터 실화면 확인 — 시도와 근본 장애 (중요)

사용자 요청으로 안드로이드 에뮬레이터(AVD `withus`)에서 실화면 확인 시도.

**성공**: 관리자 키로 `webdemo40680` 비번 복원 → 에뮬레이터 로그인·실데이터 대시보드(2024-09-15, 34점) 정상 구동 확인.

**A 화면 확인 실패 — 근본 원인**:
1. **앱은 백엔드를 실시간 호출하지 않는다** — uvicorn 로그에 앱 요청 0건. 앱은 **supabase에 저장된 분석결과를 읽는다**. A(peer_label)가 화면에 뜨려면 그 리포트를 **백엔드로 재분석해 supabase를 갱신**해야 함(이번 범위 밖 파이프라인).
2. 이 계정 리포트에 **계산기 섹션 자체가 미표시**(스크롤해도 관리 참고군까지만) — calculators 데이터가 이 리포트엔 없는 것으로 추정.
3. adb UI 자동조작이 이 앱에서 **좌표가 계속 어긋나**(탭이 엉뚱한 탭/카드 누름) 계산기 카드 도달 실패.

**대안**: 웹은 `VITE_BACKEND_URL=127.0.0.1:8000`으로 **로컬 백엔드를 실시간 호출** → playwright 로그인으로 A·D 화면 확인 가능(다음 작업 후보).

**부수 발견**: React key 중복 경고 `two children with same key 'sbp'` — 계산기(key: tyg·map 등) 아닌 **관리 참고군 항목 중복**(수축기혈압이 대사·혈압 참고군에 둘 다 포함). D 변경과 무관한 **기존 이슈**. → 향후 수리 대상.
