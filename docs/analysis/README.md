## 고칠 점

2009\~2013년 표본은 연령대 코드가 1(20\~24세)\~14이고 2014년부터는 5(20\~24세)\~18이다. `population16.py`의 나이→코드 변환은 모든 해에 2014년 방식을 써서, 2013년 이전과 견주는 16년 추세(`2026-07-29-공단표본-16년-5축-재분석.md` §4의 나이대별 변화 등)가 다른 나이대 값과 섞여 있다. 같은 해 안의 비교(또래 중 내 위치)는 영향이 없다.

## 관련 코드

- `backend/app/analyzer/_internal/population16.py` — 아래 parquet을 조회해 분석 응답에 붙인다
- `backend/data/stats/*_16yr.parquet` — `stats16_build.py`의 산출물 4종 (여기 중복 보관하지 않는다)

## 읽을 때 주의

문서는 **판단이 뒤집힌 이력을 지우지 않고 남겼다**. 특히 `2026-07-29-공단표본-16년-5축-재분석.md`의
아래 두 건은 처음 결론이 틀렸고 뒤에서 정정했으므로, 앞부분만 읽고 덮으면 틀린 결론을 얻는다.

- **조합 O/E의 지질 처리** — §1-A의 '측정자 한정'을 조합 O/E에 그대로 쓰면 안 된다.
  정정 근거는 §3-B, 어떻게 뒤집혔는지는 §9-3.
- **참고 점수 극성** — §10-4. 백엔드 `risk_score`(0=건강)를 100점 만점 필드에 그대로
  넣어 실계정에서 극성이 뒤집혀 있었다.

위의 `§N`은 `2026-07-29-공단표본-16년-5축-재분석.md`의 절이다. 각 문서 안의 `§N`은 그 문서 자체의 절을 가리키고, 다른 문서를 참조할 때는 문서명을 함께 적었다.
