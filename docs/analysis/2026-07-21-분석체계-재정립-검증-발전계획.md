## 0. 한 줄 요약
분석 체계를 **① 단일 → ② 조합(논리형 그룹 / 수식형 계산기)** 2층으로 재정립. 계산식 6종(ASCVD·eGFR·CrCl·FLI·HSI·MASLD)은 **원논문·MDCalc 검증 완료(전부 정확)**. 반면 **조합그룹은 근거 두 축(의학 의미 출처 없음 + 통계 1년치)이 모두 약함**을 확인. → "근거 있는 조합 인사이트"의 주인공은 **수치 계산기**. 발전 방향은 계산기 확충 + 조합그룹 근거 보강 + 도메인별 재편.

## 1. 분석 체계 개념 재정립 ★ (이번 작업 핵심)

### 1-A. 2층 구조
```
단일 (원자)              → 하나의 기준으로 판정/측정 (예: 비만=BMI, 고혈압=SBP/DBP)
조합 (결합해서 새 인사이트)
  ├ 논리형 = 판정(그룹)들을 AND 결합    → 출력도 범주 + 통계 = "조합그룹"
  └ 수식형 = 원시 수치들을 검증 공식 결합 → 출력은 수치(%·지수) = "계산기"
```
- **세 축은 정보 유형이 달라 서로 못 합침**(판정 Boolean ≠ 연속 수치). 계산기를 그룹(고위험군/저위험군)으로 이분화하면 what-if·정량 정보를 잃음.
- **"단일 vs 조합" 경계도 흐릿**: 대사증후군(5인자 중 3개)·이상지질혈증(LDL/HDL/TG 중 하나)도 내부적으론 조합. 순수 단일은 비만·고혈압 정도. 진짜 구분축은 **"무엇을 조합해 결과가 범주냐 수치냐"**.

### 1-B. 세 축의 정체 (정직한 규정)
| 축 | 하는 일 | 출력 | 근거 성격 |
|---|---|---|---|
| **단일그룹** (13) | 하나의 기준 판정 | 해당/비해당 | 진료지침 임계값(08 문서 검증) |
| **조합그룹** (12) | 단일그룹 AND + 공단 O/E | 범주 + 동반통계 | 공단 1년 단면 통계 (아래 §3 한계) |
| **수치 계산기** | 검증 공식으로 수치 도출 | %·지수 | **원논문·대규모 코호트 입증** |

### 1-C. 결정적 통찰 (사용자 지적)
**"여러 수치를 조합해 근거 있는 새 인사이트를 만든다"는 정의에 부합하는 건 수치 계산기다.**
- 조합그룹 O/E 2.93 = "같이 잘 뭉친다"(동반경향)일 뿐 "위험 2.93배" 아님. 거기서 `meaning`("동맥경화 가속화")으로 도약하나 **그 도약의 출처가 없음**.
- ASCVD는 "당뇨+고혈압+콜레스테롤+나이+흡연 → 위험 %"를 **입증된 공식**으로 도출 → 진짜 "조합 인사이트".

## 2. 계산식 검증 결과 (4개 영역, 원논문·MDCalc 대조)

| 계산식 | 판정 | 근거 |
|---|---|---|
| **eGFR** (CKD-EPI 2021) | ✅ 완전일치 | 142·0.9938·1.012·κ(0.7/0.9)·α(−0.241/−0.302)·−1.200 = Inker 2021 원식 |
| **CrCl** (Cockcroft-Gault) | ✅ 완전일치 | 140·72·0.85, 검산 정확 일치 |
| **FLI** (Bedogni 2006) | ✅ 완전일치 | 계수 5종·변환식·구간 원논문 일치 |
| **HSI** (Lee 2010) | ✅ 완전일치 | 경계처리(`>36`)가 원문에 충실 |
| **MASLD/MetALD/ALD** | ✅ 완전일치 | 음주컷 남>420/여>350 = 지침 남>60·여>50 g/day ×7 |
| **ASCVD** (PCE 2013) | ✅ 사실상 정확 | 베타계수 23개 전부 일치, `mean_sum`·`survival` 4값만 4자리 절사(영향 ≤0.04%p) |

**→ 발표에서 "모든 임상 계산식을 원논문·MDCalc 기준 검증"을 근거로 제시 가능.**

### 검증 중 발견한 정리거리 (오류 아님, 완성도)
1. **MASLD 심장대사 인자** — TG·HDL에 "지질강하제 복용" 조건이 주석엔 있는데 로직엔 빠짐 (combo_group_analysis.py 324-325).
2. ASCVD 4상수 고정밀 교체(선택): `61.18→61.1816` 등. 효과 미미.
3. CrCl 비만환자 체중(실체중→조정체중, 표준 논쟁).
4. 허리둘레 남90/여85 = 대한비만학회 로컬라이즈(AASLD 문자값 남94/여80과 다름 — 한국 맥락 타당).

### FLI/HSI 최신성 (2023\~2025 지침 확인)
- **유지 타당** — 2025 현재도 지방증 선별에 유효. EASL-EASD-EASO 2024 / AASLD가 폐기 안 함(영상 없으면 혈청 스코어 허용). 우리 "선별용 참고" 포지셔닝이 최신 관점과 일치.
- **단 섬유화 지표 보완 권장** — 최신 패러다임은 예후를 좌우하는 **섬유화 중심**. FLI/HSI="지방간 있나", FIB-4/BARD="위험 단계인가".
- FLI 한계: 마른체형(lean) 민감도↓, 성별 컷오프 필요.

## 3. 조합그룹 근거의 한계 (이번 작업 핵심 발견) ⚠️

조합그룹은 **근거 두 축이 모두 약함**:

### 3-A. 의학적 의미 = 출처 없음
- 각 조합의 `meaning`("당뇨 합병증 위험 가중" 등)에 **논문/지침 citation 없음**.
- `ASCVD_RISK_COMBOS`도 "학회 지침" 언급만, 구체 지침명·페이지 없음.
- 08 문서(진료지침 8종+교수 자문)는 **단일 지표 임계값**을 검증한 것이지 "조합이 왜 함께 위험한가"의 출처가 아님.

### 3-B. 통계 = 2024년 1년치 단면만
| | 보유 데이터 | 조합그룹 O/E 실제 사용 |
|---|---|---|
| 기간 | **2009–2024 (16년)** | **2024년 1개 연도만** |
| 규모 | 1,596만 행 | 99만 4천명 |

- 16년치가 있는데 **최신 1년 단면**만 씀. 대표수치 "트라이어드 O/E 2.93"도 2024년 한 해.
- 한계: ① 단면이라 예후·인과 못 봄(공존 스냅샷) ② 연도별 재현성 미검증 ③ n=99만은 크나(정밀도 OK) 설계(1년 단면)가 약함.

### 3-C. 결론
근거 비대칭이 명확:
| 조합그룹(지금) | 수치 계산기 |
|---|---|
| 의학 의미 출처 없음 | 원논문·MDCalc 검증 |
| 통계 1년 단면 | 대규모 코호트 종단·외부검증 |
| "동반 경향"(기술통계) | "입증된 위험 정량화" |

**단, 조합그룹을 버리는 게 아님** — 99만 단면도 "유병·공존율" 기술통계로는 유효. 문제는 거기에 **위험·인과 서사를 붙인 것**. → 톤다운 + 근거 보강 대상.

## 5. 추가 계산기 발굴 (MDCalc, 우리 변수로 가능)

### A. 바로 추가 가능 (검증 근거 확실)
| 계산기 | 필요변수 | 기본검진? | 근거 |
|---|---|---|---|
| **TyG index** | ln(TG×FBS/2) | 지질 있는 해 | 인슐린저항성 대리, **한국 NHANES 검증** |
| **Non-HDL-C** | TC−HDL | 지질 있는 해 | AHA/ACC 표준, SCORE2·PREVENT 입력 |
| **BARD** | BMI·AST/ALT·당뇨 | ✅ 매년 | 간섬유화 배제 NPV\~96%, 혈소판 불필요 |
| **AHA PREVENT** | +eGFR·BMI·약물 | 지질 있는 해 | PCE 공식 후속(2024, race-free), **eGFR 재활용=차별점** |
| **SCORE2/OP** | non-HDL·SBP·흡연 | 지질 있는 해 | ESC 유럽 표준(한국 region 없음→상대참고) |
| **Framingham** | TC·HDL·SBP·흡연 | 지질 있는 해 | 고전 레퍼런스 |

### A′. MDCalc 미수록이나 근거 탄탄
TyG·METS-IR·Non-HDL·AIP(log TG/HDL)·Castelli·De Ritis(AST/ALT)·LAP/VAI

### B. 부분 가능 (변수 1개 부족)
- **FIB-4·APRI**: **혈소판 필요** → 우리 검진·OCR에 혈소판 없음 → **현재 불가**. (섬유화 1차 표준이지만 혈소판 확보 전엔 못 씀 → 그래서 BARD가 유일한 섬유화 보완)
- **FINDRISC**: 설문 3문항(신체활동·과일채소·가족력) 추가 필요

### C. 불가
NAFLD Fibrosis Score(알부민·혈소판)·MELD·HOMA-IR(인슐린)·Reynolds(CRP) 등

### 발표 TOP: PREVENT(eGFR 차별점) · TyG(한국검증·최소노력) · BARD(간 서사 완성)

## 6. 발전 계획 (5개 요청 → 3 워크스트림)

사용자 요청 5개 정리: **1⊂4**(의학출처 중복), **2⊂3**(톤다운 중복) → 3덩어리.

| WS | 내용 | 성격 | 리스크 |
|---|---|---|---|
| **A. 신규 계산기** | TyG·Non-HDL·BARD (+PREVENT 선택) | 백엔드+프론트, 검산 | 낮음 |
| **B. 조합그룹 근거 보강** | 16년 O/E 재계산 + 12개 의학 출처 문서화 | 데이터 재계산 + 리서치 | 중간 |
| **C. 분석탭 재편** | 도메인별(심혈관/간/신장/대사) 재구성 + 조합 톤다운 | 프론트 | B·A 반영 필요 |

### 실행 순서
```
1단계 (병렬, 리스크 낮음)
  ├ A: TyG·Non-HDL·BARD 백엔드 + 검산 → verify: 원식 대조
  └ B-리서치: 12개 조합 의학 출처(조사) → 근거 문서
2단계
  └ B-재계산: 16년 O/E 재계산 → verify: 2024 vs 16년 비교, 연도별 재현성
       (원본 스크립트 분석 → 확장, 인구구조 변화 등 타당성 확인이 함정 지점)
3단계 (A·B 확정 후)
  └ C: 도메인 재편 + 톤다운 → verify: 브라우저 e2e, 콘솔에러 0
```
**C를 마지막에**: UI는 내용(지표·근거) 확정 후 배치해야 두 번 일 안 함.
