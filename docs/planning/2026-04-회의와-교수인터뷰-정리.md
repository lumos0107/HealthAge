# 회의록 · 교수/일반인 인터뷰 정리

> `input/새 텍스트 문서.txt` 전체 정독 정리. 프로젝트 진화 과정 + 사용자/전문가 검증의 핵심 기록.

## 1. 4/12 회의 — 인터뷰 준비 및 기능 범위 조정
- **인터뷰 방향**: 단일 테이블 변수 상관관계를 사전 조사 → 전문가에게 확인받는 형태.
- **인터뷰 질문 설계**:
  - 변수 상관: BMI 단독 정상이나 위험 올리는 수치(공복혈당·요단백·간수치 등)? / 단독 무의미하고 함께 봐야 할 변수? / 나이·성별로 해석 달라지는 변수? / **정상 범위 안이어도 추세가 중요한 변수?**
  - 시각화·커뮤니케이션: 가장 오해하는 수치 / 환자가 이해 못 하는 소견 부분 / 효과적 전달 방식(숫자·색·비교군·그래프)
- **기능 범위 조정**: 처방전 기능은 NHIS 결측치로 시계열 제외 → "내 약이 뭐고 왜 먹는지 + 부작용 안내"로 축소. 공공데이터(약-질병 매핑, 부작용) 검토.
- **피드백**: 기능 축소 시 서비스 모델 재정립 / 인터뷰 시 질문만 말고 **1장 개념도로 전체 흐름 제시** / 서비스가 타깃에 실제 도움 되는지 점검.

## 2. 4월 4주차 — 교수 인터뷰 (건강검진 경험)
대상: 학과 교수 4명(아래 A\~D). 질문 8개 요지:
- **검진 최근 수진**: 대체로 1\~2년 내.
- **결과 활용**: 위험한 부분(빨간 표시)만 봄 / 해석지 굳이 안 읽음(버리기도) / "정상·비정상" 여부만 확인, 수치 의미는 모름.
- **상담**: 안 해주거나 특이사항·소견 있을 때만. "정상이면 넘어감."
- **불편**: 기본검사 위주·세부검사 유료 / 연령대별 항목 제한 / 병원 분산.
- **서비스 의향**: 3명 긍정, 1명(D) 부정적.
- **처방전/통합관리 필요(B)**: 검진결과·피검사·처방·자가측정(혈당)을 **OCR로 텍스트 추출+자동 저장**, 연도·병원 함께 저장, 여러 병원 통합, 장기 추이(5·10년), 가족력·기저질환·복용약 관리.

**교수별 요지**
- 교수 A: 상담이 문진 수준으로 부족, 생활습관·히스토리 통합 관리 필요.
- 교수 B: 위험 부분만 확인·병원 분산 불편, OCR 통합 저장+핵심문제 표시 필요.
- 교수 C: "정상 범위 여부"만 활용, 과거 기록 연계 히스토리 도움될 것.
- 교수 D: 검진 환경·항목 불만 크고 결과 거의 미활용, **단순 평균 비교/시각화엔 부정적 — 실제 행동을 유도하는 방향 필요**.

**종합**: 검진 결과는 정상여부·위험표시만 간단 확인, 상담 제한적 → 의미 이해 어려움. 병원마다 종이·PDF 분산 → 과거 비교 어렵고 히스토리 미활용. **통합 플랫폼 + 연도별 흐름·핵심문제 직관 표시 + 진료 도움 히스토리 서비스** 필요에 공감.

## 3. 4/30 작업 — OCR 구현 및 설계
- 최종 스택: **OCR+추출=라마(로컬 LLM)**, 저장=고정컬럼+extra_data JSON, 판정텍스트=raw+normalized 병행, 정규화 3단계(정상/요관찰/유소견).
- 테스트: 결과지 이미지 → JSON 변환 성공.
- 파트 구분: OCR(라마+js) / 웹앱(Node.js) / 히스토리 DB(미정) / 분석·시각화(미정).

## 4. 5/4 회의 — 스택·프로토타입
- 프론트: React·Vite·TS / 백엔드 후보: Mongo·Neon·SQLite / 퍼블리싱: Netlify / 파일처리: Python(전처리 우위).
- 프로토타입 우선, 다중사용자 토큰관리, 시각화 우선, **일반인 2차 설문(with 프로토타입)**.
- 화면: 업로드 / OCR JSON 예시 / 히스토리 목록 / 혈당·혈압·BMI 그래프 / 문제항목 요약.
- 전처리: 연령대별 샘플링, 분산 고려.
- OCR 방식: 기존 LLM 통합 OCR(Ollama, 무료지만 성능·게시 한계) → **상용 LLM API + OCR 라이브러리 분리** 검토(성능·웹게시 우위, 유료). 예외처리: 양식 있으면 위치 기반 분기, 없으면 영역 구분 기반 분기.

## 5. 5/25 회의 — 기능·제출 조언
- **평균 비교**: 내 값 vs 평균 vs 정상범위 함께.
- **그룹군 비교**: 인자 부족 시 평균치 대체("흡연을 평균만큼 한다면 이 그룹일 것").
- **데이터 크기**: OCR 입력 이미지 **webp 전환**으로 속도 단축.
- **사용자 편의**: OCR 값별 **confidence 제공**(수정 편의), 수치 정보 제공으로 해석 도움.
- 처방전 등은 확장으로 미루고 **그룹군·시계열·평균비교 집중**.
- **제출 조언**: 어떤 과정을 겪었는지 + 선택의 결과를 비교·수치·설명으로 작성.
