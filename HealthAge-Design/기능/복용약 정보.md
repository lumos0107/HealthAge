# 복용약 정보

효능군별로 묶어 복약 정보를 표시. 없으면 '등록된 복약 정보가 없어요'.

- 코드 위치: `RecordsScreen.tsx`
- 연동 API: GET /medication/{userId}

## 시니어 관점 메모
- (사용자가 이 기능으로 하려는 일 / 어렵게 느낄 만한 점을 여기에 적기)

> 이 기능이 놓인 화면은 오른쪽 **백링크** 패널에서 확인. 화면 노트의 '포함 기능'에 링크를 넣거나 빼면 연결이 바뀐다.
