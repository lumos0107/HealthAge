# 기능 모음

이름은 팀 문서·화면 문구를 그대로 따른다(분석 카드는 질문형 이름).

## 어느 화면에도 배치되지 않은 기능 (Dataview 필요)
```dataview
TABLE 상태
FROM "기능"
WHERE type = "기능" AND length(filter(file.inlinks.file.path, (p) => startswith(p, "화면/"))) = 0
```

## 기능 수와 배치 현황 (Dataview 필요)
```dataview
TABLE length(filter(file.inlinks.file.path, (p) => startswith(p, "화면/"))) AS 배치된화면수, 상태
FROM "기능"
WHERE type = "기능"
SORT 배치된화면수 ASC
```
