# 참고 점수

0~100 종합 점수. 검사 항목별 주의/위험 개수로 감점하며, 계산기·조합·ASCVD 등은 점수에 들어가지 않는다(분석 탭이 '이 점수에 들어가지 않은 신호 N가지'를 따로 보여줌). 홈·분석에 점수가 나오고 히스토리에 '참고 점수 추이'가 있다.

- 코드 위치: `DashboardScreen.tsx / AnalysisScreen.tsx / HistoryScreen.tsx`
- 연동 API: GET /reports
