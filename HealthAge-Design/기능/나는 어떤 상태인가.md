# 나는 어떤 상태인가

집단군 판정 카드. 2뎁스에 '항목으로 보면 / 상태로 보면' 두 소제목. 이름과 값으로 무엇이 나쁜지 적는다(위험→주의 순 4개 + 나머지 보기).

- 코드 위치: `AnalysisScreen.tsx`
- 연동 API: POST /analyze

## 시니어 관점 메모
- (사용자가 이 기능으로 하려는 일 / 어렵게 느낄 만한 점을 여기에 적기)

> 이 기능이 놓인 화면은 오른쪽 **백링크** 패널에서 확인. 화면 노트의 '포함 기능'에 링크를 넣거나 빼면 연결이 바뀐다.
