# 또래보다 빠르게 변한 항목

히스토리의 '여러 해를 종합하면' 구획 카드. 악화 방향만 모아 또래 대비 변화 폭을 보여줌(분포를 보는 분석 ③층 카드와 이름으로 구분).

- 코드 위치: `HistoryScreen.tsx`
- 연동 API: GET /timeseries/{userId}

## 시니어 관점 메모
- (사용자가 이 기능으로 하려는 일 / 어렵게 느낄 만한 점을 여기에 적기)

> 이 기능이 놓인 화면은 오른쪽 **백링크** 패널에서 확인. 화면 노트의 '포함 기능'에 링크를 넣거나 빼면 연결이 바뀐다.
