# 다음 검진 목표

예전 what-if 시뮬레이터를 행동 입력으로 다시 쓴 것. 지금 걸리는 것 → 뭘 하면 → 그러면 이렇게 됩니다. 효과는 문헌 범위로 인용하고 '되면'이라는 문구를 씀.

- 코드 위치: `components/NextCheckupGoal.tsx`
- 연동 API: what_if
