# OCR 값 검수 후 저장

추출된 수치를 사용자가 확인·수정한 뒤 '이 값으로 저장할까요?'로 저장. 확인 필요 항목 표시.

- 코드 위치: `UploadScreen.tsx`
- 연동 API: POST /analyze

## 시니어 관점 메모
- (사용자가 이 기능으로 하려는 일 / 어렵게 느낄 만한 점을 여기에 적기)

> 이 기능이 놓인 화면은 오른쪽 **백링크** 패널에서 확인. 화면 노트의 '포함 기능'에 링크를 넣거나 빼면 연결이 바뀐다.
