# 이메일 로그인 회원가입

Supabase 이메일/비밀번호 인증. 실패 시 영문 에러를 상황별 한국어로 바꿔 인라인 표시(비밀번호 오류/이메일 미인증/시도 초과).

- 코드 위치: `App.tsx (AuthScreen)`
- 연동 API: Supabase Auth
