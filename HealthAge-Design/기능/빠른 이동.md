# 빠른 이동

검진기관·병원·약국 찾기(정부 사이트 연동)와 결과지 업로드로 바로 이동. 링크 열기 실패 시 안내창(openExternalUrl). 판단 요소가 아니라 도구 카드.

- 코드 위치: `DashboardScreen.tsx`
- 연동 API: 외부 URL
