# 헬스에이지 모바일 앱 디자인

건강검진 결과지를 올리면 OCR로 수치를 읽고 AI가 분석해 **참고 점수 · 연도별 추이 · 또래 비교 · 맞춤 안내**를 보여주는 React Native(Expo) 앱. 사용자는 시니어. 이 노트는 디자인 개선을 위한 기능-화면-규칙 지도다.

> 코드 문서(FRONTEND.md)의 이름은 WITHUS, 화면 문구는 '헬스에이지'. 표기 통일 필요.
> **용어는 팀 문서를 따른다.** 팀 설계 요약은 vault 밖 `docs/기존설계-통합본.md`에 있다(저장소 안, vault에는 넣지 않음).

## 구조
- `화면/` 화면 하나 = 폴더 하나 (노트 + 캡처 + 시안)
- `기능/` 기능 하나 = 노트 하나. 입구는 [[기능 모음]]
- `규칙/` 시니어 디자인 규칙. 각 화면의 '규칙 체크'가 링크

## 화면 흐름
하단 탭 5개: [[홈]] · [[검사항목]] · [[히스토리]] · [[분석]] · [[업로드]]
헤더 아이콘: [[프로필]]
그 밖: [[로그인]] · [[빈상태]] · [[항목 상세]]

## 핵심 과업 (초안, 직접 확정하기)
시니어가 앱으로 매번 하려는 일 3개 이하로 줄이기. 후보:
1. 검진 결과지 올리기 → [[업로드]]
2. 지금 내 상태·주의 항목 확인 → [[홈]]
3. 해마다 변화 보기 → [[히스토리]]
